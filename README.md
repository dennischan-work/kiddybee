# 沙田英文中心試算台

沙田幼兒英語教育中心開業規劃的互動試算頁。調整左邊的假設，即時比較三條開業路線：

- 私人小班工作室（一間課室，創辦人親自授課）
- 註冊中心 · 分階段（學生達 45 人後擴編）
- 註冊中心 · 全編制（一開始請齊人手）

## 頁面內容

| 部分 | 回答的問題 |
| --- | --- |
| 三條路線一覽 | 每條路線的打平人數、學生上限、首年營運結果、現金最低點、建議準備資金 |
| 現金曲線 | 開業後 18 個月，錢在哪個月最緊 |
| 打平與容量 | 打平所需學生，課室裝不裝得下 |
| 定價敏感度 | 每堂收費高一點，打平人數少多少 |
| 創辦人的一週 | 每週要教幾堂、幾小時，週六會否接近每日 20 人門檻 |

## 怎樣打開

直接用瀏覽器打開 `index.html` 即可，毋須安裝任何東西。字體由 Google Fonts 載入，離線時會改用系統字體。

如要放上網，可在 repo 的 Settings › Pages 選擇 `main` 分支根目錄。

| --- | --- |

## 注意

- 全部數字是規劃假設，不是報價、批准條件或保證結果。
- 未計稅、融資及回收開業投資；創辦人薪酬只在頁面中設定後才計入。
- 「創辦人親自授課」開啟時，註冊中心兩個方案都扣除一名全職導師成本；關閉時回到手冊人手假設。
- 工作室由創辦人一人授課時，如創辦人不是外籍導師，NET 課程比例應設為 0，否則收入會被高估。
- 是否須向教育局註冊，以教育局對實際營運時間表的書面回覆為準。
