# 沙田幼兒英語教育中心｜開業規劃網站

給創辦人和出資人用同一組數字討論開業方案。全部數字是規劃假設，不是報價、批准條件或保證結果。

## 頁面

| 頁面 | 內容 |
| --- | --- |
| `index.html` 規劃總覽 | 中心定位、兩條開業路線、手冊與投資人兩個財務口徑、按資金上限看可行方向、分段撥款與關卡、三情境現金需求、停損線與最大虧損、開業時間表、合規流程、十四步、課程與招生、待確認事項 |
| `calculator.html` 試算台 | 調整假設，即時比較私人小班工作室、註冊中心分階段、註冊中心全編制三條路線 |

## 試算台

- 上半部：註冊中心開業方式（方案 A 新址申請／方案 B 頂手），標示為高風險路線；預設：每月 4.0 週、60 分鐘小班 HK$330、每月流失 4%、租金 HK$25,000、按金 3 個月、裝修連消防 HK$300,000、圖則顧問 HK$80,000、頂手價 HK$250,000（放盤叫價參考）、家具教材 IT HK$80,000、審批期 5 個月租金（跟創辦人計劃書時間表）、一對一佔比可調（預設 0%）、創辦人每週教 22 堂且薪酬另計、超出部分請兼職導師每堂 HK$200、兼職行政 HK$8,000；並列出中心需要準備的現金、對比可動用資金、招生慢三成、審批延遲 3 個月及創辦人每月支薪 HK$20,000 時的結果。
- 下半部：私人小班工作室，兩組預設「目前規劃（兩間課室）」及「精簡一人工作室」（網址加 `#risk-check` 直接開精簡版）；預設課表每日不超過 19 人。
- 聘用老師：逐位填月薪（老師 A／B／C／D），可選計入僱主強積金（5%，每人每月上限 HK$1,500），並設定各路線聘用人數。
- 工作室可選 1–4 間課室、0–4 位老師；可同時開班的課室＝min（課室數，創辦人＋老師）。工作室學位另受每個時段最多 7 人、每日最多 19 人限制（試營運構想，須教育局確認）。
- 行政人員：每位月薪及各路線人數（預設 HK$17,000 取自市場研究估算，未經核實）。
- 註冊中心可同時開班的課室數＝創辦人加聘用老師人數，最多兩間。
- 學生增長曲線可選手冊曲線、投資人基準、投資人審慎（投資人兩條以直線近似）。
- 創辦人的一週：點擊課表格子加減時段（空白 → 開班 → 需求不穩），課表班數即「每間課室每週可售班數」；每週可售班數＝可同時開班的課室 × 課表班數。會即時顯示打平要平均每班幾人、每日人數是否觸及 20 人、平日 19:00 後時段、連續上課等提醒。
- 每班人數以整數 1–7 人設定，超過中心自訂的每班上限 4 人會出現提醒。政府沒有規定工作室每班人數，看的是全機構同時 8 人及每日 20 人門檻。
- 每個選項旁有 i 圖示，點擊看簡短說明。
- 老師預設月薪 HK$28,500 依手冊「全職導師連僱主成本 HK$30,000」反推，不是市場行情；強積金按現行上限計，積金局正在檢討。

## 資料來源

〈沙田幼兒英語教育中心 開業及營運完整手冊 整合加強版〉及〈沙田幼兒英文中心｜投資人可執行方案（HK$100 萬）〉，兩者均為 2026 年 10 月 30 日版本；開業目標以 2027 年 8 月為準。市場參考（2026 年 10 月查閱）：沙田商業中心寫字樓放盤約 HK$20／呎、沙田／馬鞍山補習中心全職導師招聘底薪約 HK$17,000–22,000、同類 60 分鐘小班約 HK$250–330。總覽頁「可行方向」的分級及打平人數的進位，是由兩份文件數字推算。

## 怎樣打開

直接用瀏覽器打開 `index.html` 即可。放上網：repo 的 Settings › Pages 選擇 `main` 分支根目錄。兩頁都設了 `noindex`，不會被搜尋引擎收錄；拿到連結的人仍可打開。
